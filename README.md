# Shinkansen Passenger Satisfaction Prediction — Top 10 Hackathon Solution

## Overview
This repository contains my solution for the Machine Learning Hackathon from the MIT Applied AI & Data Science Program by Great Learning.
The objective of the competition was to build a machine learning pipeline capable of accurately predicting passenger satisfaction using survey and travel-related data.
My final solution achieved a Top 10 leaderboard ranking (#9, subject to final review) through extensive experimentation, feature engineering, threshold optimization, cross-validation strategies, and iterative model tuning.

## Problem Statement
The challenge focused on predicting passenger satisfaction based on:
- Passenger survey data
- Travel-related operational data
- Service quality indicators
- Customer experience variables

## The primary evaluation metric for the competition was:
Accuracy Score
